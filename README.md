# Equation Notes

This is a simple mathematical notes-taking application designed for IOS using Swift. It aims to allow users to combine rendered LaTeX, body text and photos in an easy to edit and view way. Additionally, it uses OCR to identify a few mathematical characters.


# Installation and usage

To run this application, you'll need Git and Xcode. Simply clone the repository into a new folder using Git. You are then advised to open the .xcodeproj file in Xcode. The application can be run either through an Xcode simulator, or by using your phone as a simulator and loading the application onto your phone through Xcode.

Minimum software requirement of IOS 17.5

## Dependencies

This application depends on one external library, LaTeXSwiftUI. This is used to render LaTeX code and should come preinstalled with the repository.
